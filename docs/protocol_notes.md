# PIC-10 离子色谱仪通讯协议与动作模型

来源：`PIC系列离子色谱分析仪反控通讯协议V2-公开.pdf`。

本文把 PDF 中的寄存器协议转换成语音交互可以使用的动作模型。动作规划器只生成结构化计划，不直接连接仪器；真正发包前还需要 `InstrumentClient` 完成地址、功能码、字节序和校验码编码。

## 1. 协议基础

| 项目 | PDF 内容 |
|---|---|
| 设备 | PIC-10 型在线离子色谱分析仪 |
| 物理接口 | RS232，DB9-2 TXD、DB9-3 RXD、DB9-5 GND |
| 串口参数 | 9600, n, 8, 1 |
| 从站地址 | 说明文字给出默认 `0x11` |
| 读功能码 | `0x03`，读取寄存器 |
| 写功能码 | `0x06`，写单个寄存器 |
| 数据 | 表格中的寄存器通常按 4 字节内容表示，实际有效值可能是末 1~2 字节 |
| 校验 | PDF 写作 LRC 8-bit，写入示例标注 `LRC` |

协议实现前必须做一次实机抓包确认。PDF 第 3 页的读请求示例地址显示为 `0x06`，但同页说明默认地址为 `0x11`；同时文档称为 Modbus RTU，而校验又写作 LRC，和标准 Modbus RTU 常见的 CRC-16 不一致。这些参数不能只凭文档猜测。

读请求的逻辑字段为：

```text
[slave address][0x03][start address hi][start address lo]
[register count hi][register count lo][check]
```

写请求的逻辑字段为：

```text
[slave address][0x06][register address hi][register address lo]
[data hi][data lo][check]
```

PDF 的寄存器表把一个寄存器内容写成 4 字节，例如 `00 00 XX XX`。动作层保留完整的 4 字节值；串口适配层应按设备实测结果决定写单个 16 位有效值，还是拆成多次写入。

## 2. 寄存器动作分组

### 2.1 设备信息（1000 区）

| 地址 | 内容 | 方向 | 语义 |
|---|---|---|---|
| `0x1001` | 设备标志编码 | R | 前 3 字节固定为 `P/M/TYPE`；TYPE 表示设备型号，DEVICE 位图表示电导、伏安、平流泵、淋洗液发生器等模块存在性 |
| `0x1003` | 当前日期 | R/W | 4 字节，16 进制表示年月日 |
| `0x1004` | 当前时间 | R/W | 4 字节，16 进制表示时分秒 |

### 2.2 电导检测器（2100 区）

| 地址 | 内容 | 方向 | 单位/编码 |
|---|---|---|---|
| `0x2100` | 进样/分析状态 | R/W | `X=0` 进样，`X=1` 分析；设备会主动上送状态 |
| `0x2101` | 电导档位 | R/W | `0..8` |
| `0x2102` | 电流设定 | R/W | mA，2 字节整数 |
| `0x2103` | 输出调零 | W | `00 00 00 00` |
| `0x2111` | 档位电压 | R | uV |
| `0x2112` | 电导 | R | uS/cm |
| `0x2113` | 实际电流 | R | uA |
| `0x2114` | 调零输出 | R | uV |
| `0x2115` | 温度 | R | 摄氏度，原始值除以 1000 |

### 2.3 泵与淋洗液发生器（2120~214A）

| 地址 | 内容 | 方向 | 单位/编码 |
|---|---|---|---|
| `0x2120` | 泵流量设定 | R/W | mL/min，原始值除以 100 |
| `0x2121` | 泵最大压力 | R/W | MPa，原始值除以 10 |
| `0x2122` | 泵最小压力 | R/W | MPa，原始值除以 10 |
| `0x2123` | 流量校正参数 | R/W | 2 字节整数 |
| `0x2125` | 泵启动/停止、泵状态 | W/R | 写 `X=1` 启动，`X=0` 停止；读回状态 |
| `0x2126` | 泵清洗 | W | `00 00 00 00` |
| `0x2127` | 泵压力校正 | W | `00 00 00 00` |
| `0x2128` | 当前泵压力 | R | MPa，原始值除以 100 |
| `0x2130` | 淋洗液发生器设置 | R/W | `S` 表示梯度启用标志，`XX XX` 为发生器电流 |
| `0x213F` | 发生器实际电流 | R | `00 00 XX XX` |
| `0x2131`~`0x213A` | 梯度淋洗时间段 1~10 | R/W | 时间 MM 以分钟计，另含发生器电流和四元泵通断位 |
| `0x2141`~`0x214A` | 梯度淋洗电流段 1~10 | R/W | 起始电流 SC、终止电流 EC，单位 mA |

### 2.4 伏安检测器（3100 区）

| 地址 | 内容 | 方向 | 单位/编码 |
|---|---|---|---|
| `0x3100` | 空闲/分析状态 | R/W | `X=0` 停止/空闲，`X=1` 分析；最高位可能表示仪器自身启动，不等同于上位机命令 |
| `0x3101` | 单电位档位 | R/W | `0..7` |
| `0x3102` | 单电位电压设定 | R/W | mV，范围 -2500~+2500 |
| `0x3103` | 输出调零 | W | `00 00 00 00` |
| `0x3104`~`0x3109` | 脉冲方式 T1/T2/T3/TX/TY/DT | R/W | mS，0~1000 |
| `0x310A`~`0x310D` | 脉冲方式 D1/D2/D3/DE | R/W | mV，-2500~+2500 |
| `0x310E` | 脉冲前延时 | R/W | 秒，0~3600 |
| `0x310F` | 脉冲后延时 | R/W | 秒，0~3600 |
| `0x3110` | 脉冲重复次数 | R/W | 小于 10 |
| `0x3111` | 给定电压实测值 | R | uV |
| `0x3112` | 实际电流 | R | uA |
| `0x3113` | 单电位调零输出 | R | uV |
| `0x3114` | 文档标注不清的调零输出项 | R | 需要向厂家确认名称和含义 |
| `0x3115` | K1 模式 | R/W | `0` 脉冲模式，`1` 单电位模式 |
| `0x3116` | 脉冲方式 T4 | R/W | mS，0~1000 |
| `0x3117` | 脉冲方式 D4 | R/W | mV，-2500~+2500 |

### 2.5 自动进样器（4100 区）

| 地址 | 内容 | 方向 | 单位/编码 |
|---|---|---|---|
| `0x4101` | 空闲/分析状态、停止/启动控制 | R/W | 写 `0` 停止，`1` 启动；读回 AN、BN、OPH、OPL |
| `0x4102` | 起始瓶号和结束瓶号 | R/W | `FP` 起始瓶，`EP` 结束瓶 |
| `0x4103` | 分析时长、次数 | R/W | AN 分析次数，CN 清洗次数，TH:TL 为分析时长 |
| `0x4104` | 检测器选择 | R/W | CSEL bit0/bit1 控制通道；CH1/CH2：0 电导、1 伏安、2 紫外 |
| `0x4105` | 自动稀释参数 | R/W | 定量体积最大约 500 uL；RN=`01` 不稀释、`02` 50%、`05` 20%、`10` 10% |
| `0x4112` | 转到下一个瓶子 | W | `00 00 00 00` |
| `0x4113` | 回到起始位置 | W | `00 00 00 00` |
| `0x4114` | 位置纠偏 | R/W | Adj，每 400 步一周 |
| `0x4115` | 当前位置/到达指定位置 | R/W | 读 T、C；写 `C` 指定瓶号；`OPH:OPL=E000` 表示定位完成 |
| `0x4116` | 进样 | W | `0x50` 开始进样，`0x00` 停止进样 |
| `0x4117` | 抬针/落针 | W | 最高位 `0` 抬针，`1` 落针 |
| `0x4120` | 样品位置纠偏值 | R/W | HH LL |
| `0x4121` | 清洗位置纠偏值 | R/W | HH LL |
| `0x4122` | 当前 Y 轴纠偏 | W | S=`0`，Y+1；S=`1`，Y-1 |
| `0x4123` | 当前 X 轴纠偏 | W | S=`0`，X+1；S=`1`，X-1 |
| `0x4124` | 纠偏确认 | W | `00 00 00 01`，实际写入进样器 |

## 3. 可供语音层使用的动作

### 3.1 已能直接映射的动作

| 语音意图 | 协议动作 |
|---|---|
| 设置流速 | 写 `0x2120 = round(flow_ml_min * 100)`，再读回确认 |
| 设置压力上限 | 写 `0x2121 = round(pressure_mpa * 10)`，再读回确认 |
| 启动/停止泵 | 写 `0x2125 = 1/0`，再读回状态 |
| 泵清洗 | 写 `0x2126 = 0` |
| 泵压力校正 | 写 `0x2127 = 0`，必须二次确认 |
| 查询当前压力 | 读 `0x2128`，原始值除以 100 |
| 查询当前流速 | 读 `0x2120`，原始值除以 100 |
| 设置电导电流 | 写 `0x2102`，单位 mA |
| 电导输出调零 | 写 `0x2103 = 0`，必须二次确认 |
| 选择进样瓶 | 写 `0x4115`，等待定位完成标志 |
| 抬针/落针 | 写 `0x4117` |
| 开始/停止进样 | 写 `0x4116 = 0x50/0x00` |
| 启动/停止自动进样分析 | 写 `0x4101 = 1/0` |
| 设定起止瓶和次数 | 写 `0x4102`、`0x4103` |
| 选择检测器通道 | 写 `0x4104` |

### 3.2 需要组合成序列的动作

“开始进样”至少需要：

```text
读取 0x4115 当前位置信息
→ 写 0x4115 目标瓶号（如果目标瓶尚未定位）
→ 轮询 0x4115，直到 OPH:OPL=E000
→ 写 0x4117 落针
→ 写 0x4116=0x50 开始进样
```

“停止运行/急停”应由安全策略决定具体范围。建议初版顺序为：

```text
写 0x4116=0x00 停止进样
→ 写 0x4101=0 停止自动进样器
→ 写 0x3100=0 停止伏安分析
→ 写 0x2125=0 停止泵
→ 读取 0x2125、0x3100、0x4101 验证停止状态
```

`0x2100` 不应被当作“电导停止”寄存器：PDF 定义 `X=0` 为进样、`X=1` 为分析，因此停止序列不能向该地址写 `0`。

“开始采集”不能只翻译成一个通用的 `start_acq`。协议把电导、伏安和自动进样器分开控制，必须先根据 `0x4104` 的检测器配置决定是否写 `0x2100=1`、`0x3100=1`、`0x4101=1`，否则规划器应返回 `needs_clarification`。

### 3.3 当前协议没有直接覆盖的项目

- 柱温设定：协议只有 `0x2115` 的检测器温度读取，没有柱温控制寄存器。
- 检测波长设定：协议没有波长寄存器；`0x3102` 是伏安单电位电压，不能当成波长。
- 峰面积、保留时间、基线稳定、保存谱图、导出报告、比较色谱图：属于上位机数据处理或文件操作，不是本 PDF 中的仪器寄存器动作。
- “排气泡”“洗针”“平衡色谱柱”：可以由泵清洗、自动进样器定位/进样、泵启动和状态轮询组合，但 PDF 没有分别给出同名的单一命令，必须结合仪器操作定义确认。

## 4. AI 动作规划接口

语音识别文本进入规划器时，建议让模型只输出下面的结构，不允许直接输出十六进制报文：

```json
{
  "schema_version": "instrument-action-plan.v1",
  "intent": "set_flow",
  "status": "ready",
  "confidence": 0.98,
  "actions": [
    {
      "op": "write_register",
      "register": "0x2120",
      "value": 100,
      "unit": "raw",
      "description": "设置泵流量为 1.00 mL/min"
    },
    {
      "op": "read_register",
      "register": "0x2120",
      "description": "回读确认流量"
    }
  ],
  "warnings": []
}
```

规划器的安全规则：

1. `actions` 只能引用注册表中的寄存器和允许的值域。
2. 所有写动作都要带单位换算和范围检查。
3. 启停泵、启动分析、进样、校正、调零属于有副作用动作，必须附回读验证；急停可直接执行，但仍要回读。
4. 检测器选择、目标瓶号、起止瓶号等信息不完整时返回 `needs_clarification`，不能猜测。
5. LLM 只负责意图、参数和顺序；报文编码、校验、超时、重试由确定性的协议适配器完成。

## 5. 实施顺序

1. 先用 `0x1001` 读取设备标志，确认设备型号和模块存在性。
2. 用只读请求验证 `0x2128`、`0x2115`、`0x4115`，确认地址、字节序、缩放和校验。
3. 再实现流量、压力上限、泵启停三个低复杂度动作。
4. 接着实现自动进样器定位/进样状态机。
5. 最后实现检测器选择、梯度和多模块启动序列。
